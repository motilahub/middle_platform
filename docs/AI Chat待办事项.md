## 下一阶段优先事项

### 对话体验

- [ ] 停止生成：中断浏览器请求和服务端模型流，并正确记录失败状态。
- [ ] 重新生成：对失败或不满意的助手消息重新发起请求。
- [ ] 编辑并重发用户消息。
- [ ] 会话重命名、会话搜索和最近使用排序。
- [ ] SSE 断线重连、超时提示和网络恢复后的状态同步。
- [ ] Markdown、代码高亮和长消息复制。

### 附件与输入

- [ ] 接入平台文件中心，避免 AI 模块单独管理文件生命周期。
- [ ] 增加 MIME 白名单、病毒扫描和文件内容解析任务。
- [ ] PDF、Office、纯文本和压缩包的解析策略。
- [ ] 将图片按模型能力转换为真正的视觉输入，而不是只传文件名。
- [ ] 支持语音原文件保存、转写状态和转写失败重试。
- [ ] 记录附件引用的下载权限和审计日志。

### 知识库与 Skill

- [ ] 文档分块、向量化和向量数据库索引。
- [ ] 混合检索、召回分数、引用来源和引用片段展示。
- [ ] 知识库文档上传、更新、删除和索引状态管理。
- [ ] Skill 注册、版本、权限、参数 Schema 和执行结果校验。
- [ ] 工具调用前确认、超时、重试、幂等和审计记录。

### 模型与运维

- [ ] 声明模型的文本、视觉、音频、工具调用能力矩阵。
- [ ] 统计首 token 延迟、总耗时、输入/输出 token 和费用。
- [ ] 供应商限流、重试、熔断和备用模型策略。
- [ ] 统一错误码、敏感信息脱敏和管理员审计查询。
- [ ] 增加端到端测试：登录、创建会话、上传附件、流式回复和移动端布局。

## 暂不纳入当前阶段

- WebSocket/Realtime 实时语音对话。
- 多模型并行回答和复杂 Agent 编排。
- 未经权限审核的第三方 Skill 自动安装。
- 将完整附件原文无条件发送给不支持对应模态的模型。

## 验收标准

- 文本回复首 token 可在合理时间内出现，增量内容实时渲染。
- 刷新页面后会话、消息和附件仍然可见，且不同用户互不可见。
- 手机宽度下输入框、发送按钮和模型选择均无需滚动页面即可操作。
- 所有附件、知识库和 Skill 请求均经过登录态、权限和大小校验。
